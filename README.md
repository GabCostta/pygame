# Player Jump
"Player Jump". O objetivo do jogo é controlar o jogador (player) enquanto ele pula e evita inimigos.

## Como Jogar
1. **Iniciar o Jogo**: Pressione `SPACE` no menu principal para começar.
2. **Mover o Jogador**: Use as setas `LEFT` e `RIGHT` para mover o jogador.
3. **Pular**: Pressione a seta `UP` para pular.
4. **Evitar Inimigos**: Desvie dos inimigos que se movem pela tela.
5. **Vidas**: O jogador começa com 3 vidas. Ao perder todas as vidas, o jogo reinicia.

## Controles
- `SPACE`: Iniciar o jogo
- `M`: Alternar música
- `Q`: Sair do jogo
- `LEFT/RIGHT`: Mover o jogador
- `UP`: Pular

## Estrutura do Projeto
- **Imagens**: Localizadas na pasta `images/`.
- **Música**: Localizada na pasta `music/`.
- **Sons**: Localizados na pasta `sounds/`.

## Requisitos
- Python 3.13 ou superior
- Pygame Zero instalado (`pip install pgzero`)

## Como Executar
1. Certifique-se de que todos os arquivos estão no diretório correto.
2. Execute o comando:
   ```
   python player-jump.py
   ```
